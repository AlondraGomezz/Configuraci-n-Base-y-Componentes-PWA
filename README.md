
# Portafolio de ejercicios: Aplicaciones Web Progresivas (PWA)

## Descripción

Este portafolio contiene cinco ejercicios prácticos enfocados en la construcción de la infraestructura técnica básica de una Aplicación Web Progresiva (PWA).

Se trabajaron la configuración del manifiesto, la interfaz base, el ciclo de vida del Service Worker, el almacenamiento en caché y el funcionamiento sin conexión.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Web App Manifest
- Service Workers
- Cache API
- Google Chrome DevTools
- Visual Studio Code
- Live Server

## Ejercicios

### Ejercicio 1: Web App Manifest y metadatos
Configuración del archivo manifest.json, propiedades de instalación e integración de iconos PNG de 192x192 y 512x512 píxeles.

### Ejercicio 2: App Shell y Splash Screen
Creación de una interfaz responsiva con encabezado, navegación y contenido principal. Verificación de la instalación de la PWA.

### Ejercicio 3: Registro y ciclo de vida del Service Worker
Registro asíncrono del Service Worker e implementación de los eventos install, activate y fetch.

### Ejercicio 4: Cache API y estrategia Cache-First
Almacenamiento de recursos estáticos y recuperación desde caché antes de consultar la red.

### Ejercicio 5: Interceptor de peticiones y modo offline
Implementación de una página personalizada de respaldo cuando una navegación no está guardada en caché y no hay conexión a Internet.

## Cómo ejecutar los ejercicios

1. Descargar o clonar este repositorio.
2. Abrir la carpeta del ejercicio que se desea probar en Visual Studio Code.
3. Ejecutar el archivo index.html utilizando la extensión Live Server.
4. Utilizar Google Chrome DevTools para revisar el manifest, el Service Worker y Cache Storage.
5. En el Ejercicio 5, utilizar la pestaña Network de DevTools para simular el modo Offline.
